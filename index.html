Conexión con Supabase y GitHub

Aprende a integrar Supabase como base de datos en la nube y desplegar gratis esta web en GitHub Pages o Vercel.

Configurar Cliente Supabase

Ingresa la URL del proyecto y la clave pública (Anon Key) obtenidas de tu panel de Supabase para activar la sincronización remota.

Guía Paso a Paso para Despliegue

1 Crear Proyecto en Supabase

1. Ve a supabase.com y crea una cuenta gratuita.
2. Crea un nuevo proyecto. Copia la URL del proyecto y la Anon Key desde Project Settings -> API y pégalas arriba.

2 Crear Tablas en Supabase (SQL Script)

Ve al menú SQL Editor dentro de tu panel de Supabase y ejecuta la siguiente consulta SQL para estructurar la base de datos:

-- 1. Tabla de Categorías
CREATE TABLE categories (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  name TEXT NOT NULL,
  type TEXT NOT NULL CHECK (type IN ('ingreso', 'gasto')),
  icon TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Tabla de Transacciones
CREATE TABLE transactions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  amount NUMERIC(10,2) NOT NULL,
  type TEXT NOT NULL CHECK (type IN ('ingreso', 'gasto')),
  category TEXT NOT NULL,
  description TEXT,
  date DATE NOT NULL DEFAULT CURRENT_DATE,
  frequency TEXT DEFAULT 'único',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. Tabla de Presupuestos
CREATE TABLE budgets (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  category TEXT UNIQUE NOT NULL,
  monthly_limit NUMERIC(10,2) NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Habilitar Políticas de Lectura/Escritura Pública (Desarrollo/Uso Personal)
ALTER TABLE categories ENABLE ROW LEVEL SECURITY;
ALTER TABLE transactions ENABLE ROW LEVEL SECURITY;
ALTER TABLE budgets ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Permitir todo a usuarios anonimos" ON categories FOR ALL USING (true);
CREATE POLICY "Permitir todo a usuarios anonimos" ON transactions FOR ALL USING (true);
CREATE POLICY "Permitir todo a usuarios anonimos" ON budgets FOR ALL USING (true);
3 Publicar en GitHub / Vercel

1. Crea un repositorio en GitHub llamado mi-contabilidad-hogar.

2. Guarda este código HTML en un archivo denominado index.html.

3. Sube el archivo al repositorio e interactúa mediante comandos de Git:

git init
git add index.html
git commit -m "Inicializar app de contabilidad del hogar"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/mi-contabilidad-hogar.git
git push -u origin main

4. Activa GitHub Pages en la sección Settings -> Pages seleccionando la rama main, ¡y tu app estará en vivo gratis!
